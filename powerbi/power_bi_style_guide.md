# Power BI Style Guide

## Purpose:

This style guide defines the visual standards used throughout the Managed Care Analytics Dashboard

The goal is to create a clean, executive-friendly dashboard that emphasizes readability and business insights over visual complexity.

---

# Overall Design Philosophy

The dashboard should answer business questions quickly

Every visual should:

- communicate one primary idea,
- minimize unnecessary decoration,
- use consistent formatting,
- and support health decision-making.

Whenever possible, allow the data (not the formatting) to attract attention.

---

# Color Palette

## Primary

Healthcare Maroon
```
#8C1D40
```

Use for:
- Page titles
- KPI highlights
- Primary data series

---

## Secondary

Slate Gray
```
#6B7280
```

Use for:
- Secondary data series
- Axis labels
- Supporting text

---

## Accent

Muted Gold
```
#C9A227
```

Use sparingly for:
- Selected categories
- Highlights
- Important comparisons

---

## Positive

Forest Green
```
#2E7D32
```

Use for:
- Positive trends
- Goal achievement
- Favorable quality metrics
